# wooCommerce-SKU-display-additional-info-WP
🚀🤖 AI‑Enhanced (GPT‑5) WooCommerce snippet appends the product’s SKU as the final row in the “Additional Information” attribute table. Keeps SKU aligned with structured product details instead of displaying it above the tabs. Lightweight, theme-safe, and works with WPCode, Code Snippets, or a child theme’s functions.php.
